# Lumus

A Google TV–style home screen for Amazon Fire TV (Fire OS 6 / Android 7.1), with live content and Home Assistant control.
Package: `dev.davobr.lumus`.

Based on [CleanYourTV](https://github.com/Gathin23/cleanyourtv) (MIT) and its Fire OS Home watcher
([tv-vibehack, fire-tv-support](https://github.com/ljis120301/tv-vibehack/tree/fire-tv-support)), back-ported to API 25.

## Features
- **Home watcher**: Fire OS won't let a third-party launcher own Home; `HomeWatchService` follows the system log and
  brings Lumus up over Amazon's home (needs `READ_LOGS` and `SYSTEM_ALERT_WINDOW`).
- **Carousel**: all apps in one row of circles at the bottom, high-res icons, bundled full-bleed icons in `assets/icons/<package>.png`.
- **Continue watching**: Netflix recommendations (notification listener `RecsListener`) and Plex On Deck / Recently Added
  (`PlexClient`, linked with a plex.tv/link code).
- **Cartelera theme**: TMDB weekly trending backdrops as rotating wallpaper with titles (`TmdbBackdrops`); plus the CleanYourTV themes, picked in Launcher settings.
- **Weather** beside the greeting (Open-Meteo, no key) and a **Home Assistant summary** (lights on, ACs running).
- **Casa panel**: Home Assistant areas, lights, switches, climate, media players; hold OK for brightness / temperature / mode.
- **Navigation sounds** (soft, Apple TV-like, generated by `sfx/make_appletv_sfx.py`).
- Fire OS settings dropdown on the Settings pill.

## Build
JDK 17+ (21 works) and the Android SDK (platform 34, build-tools 34):
```bash
echo "sdk.dir=$ANDROID_HOME" > local.properties
./gradlew assembleDebug
```
Updates must be signed with the same key as the installed build (kept outside this repo).

## Install / device setup (adb)
```bash
adb install -r app/build/outputs/apk/debug/app-debug.apk
P=dev.davobr.lumus
adb shell pm grant $P android.permission.READ_LOGS
adb shell pm grant $P android.permission.ACCESS_FINE_LOCATION
adb shell appops set $P SYSTEM_ALERT_WINDOW allow
adb shell settings put secure enabled_notification_listeners $P/dev.davobr.lumus.RecsListener
```

## Secrets (never committed)
Pushed to `/sdcard/Android/data/dev.davobr.lumus/files/`:
- `tmdb_token` – TMDB read access token (Cartelera theme)
- `ha.json` – `{"url": "http://<ha>:8123", "token": "<long-lived token>"}` (Casa panel and summary)

Plex is linked on the TV (Launcher settings → Plex) and its token stays in the app's private storage.
